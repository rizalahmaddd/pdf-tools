# Security Policy

## Zero-Server Processing & Privacy Guarantee

**PDF Toolkit** is designed with privacy as the core architecture principle:
- **100% Client-Side:** All document processing (merging, splitting, OCR, signing, redact, compressing, etc.) runs entirely inside your browser using WebAssembly and Web Workers.
- **Zero Network Transmission:** No documents, files, form values, or metadata are ever transmitted, logged, or uploaded to any remote server or third-party service.
- **Offline Capable:** The application operates identically with network access disabled or directly from local storage (`file://`).

## Reporting a Security Concern

If you discover a security vulnerability, issue, or unintended network leak within this project, please report it responsibly:

1. **GitHub Security Advisory:** You can submit a private vulnerability report via [GitHub Security Advisories](https://github.com/rizalahmaddd/pdf-tools/security/advisories/new).
2. **Direct Contact:** You can also contact the maintainer directly via WhatsApp at [+62 857-7777-5477](https://wa.me/6285777775477).

Please provide:
- A description of the issue.
- Steps or a proof-of-concept to reproduce the behavior.
- Browser name and version used.

We will review reports promptly and take necessary corrective actions.
